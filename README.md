# Hand in Hand

A static sign-language learning project with alphabet-based translators and a Zimbabwean Sign Language (ZSL) photo dictionary. It uses HTML, CSS, browser JavaScript, and a JSON dictionary index; no PHP or build step is required.

## Run locally or deploy

Serve the project folder from any static web server or hosting service, then open `index.html`. The photo lookup uses a JavaScript image index, so it also works when opening the pages directly as `file://` URLs in browsers that allow local files. A full local deployment uses the HTML, CSS, JavaScript, and `dictionary/` image folder together, preserving their relative paths. The GitHub Pages workflow below intentionally omits dictionary photo snippets.

### Publish with GitHub Pages

The repository includes a GitHub Actions workflow for publishing the static site. Push this project to a GitHub repository on the `main` branch, then select **Settings → Pages → Build and deployment → GitHub Actions**. The workflow publishes the site on each push to `main`; the public URL will be `https://<username>.github.io/<repository>/`. Camera and microphone features require HTTPS, which GitHub Pages provides. Confirm that the Pages URL loads successfully from your device and network before sharing it.

The workflow publishes the HTML pages and the `css/`, `images/`, and `js/` folders, plus only the ZSL and American Sign Language PDF references from `dictionary/`. It deliberately excludes the dictionary photo snippets, assignment documents, shortcut, and demo ZIP. The hosted version advertises the PDFs and uses ASL alphabet images only for fingerspelling; it does not claim that those handshapes are ZSL signs. The deployment workflow checks that the dictionary folder contains exactly the two PDFs before publishing.

## What is included

- The home page links to the ZSL, American Sign Language (ASL), and British Sign Language (BSL) learning tools.
- The home page also links to `voice-to-sign.html`, where typed or browser-recognized English is presented in a video-style player as ordered ZSL dictionary photos, indexed ASL illustrations, and ASL alphabet handshape images for words missing from both sources. Playback supports pause, stepping, and speed control. The available source material is still images, not continuous signing footage or a fluent sign-language translation.
- The home page also links to `videototext.html` (“Video to Text”). It requests camera permission and supports manual transcript editing and automatic dictionary lookup. Genuine camera transcription requires a sign-language-specific model: define `window.HAND_IN_HAND_VIDEO_TO_TEXT_PROVIDER` before `js/video-to-text.js` loads, with `language` or `languages` declaring supported language codes (`zsl`, `asl`) and an async `recognizeFrame({ video, language })` method returning `{ text, isFinal, confidence }`. The method is called about every 300 ms; interim results should set `isFinal: false`, and only new finalized text should set `isFinal: true`. Confidence, when supplied, must be between 0 and 1. Without a compatible provider, the page shows camera preview but deliberately does not guess signs. Transcript words automatically use the existing ZSL-first dictionary search with labelled ASL references/fingerspelling fallback. Camera access requires HTTPS or localhost. A provider may transmit camera frames outside the browser; review its privacy terms and disclose that processing before enabling it. No sign-recognition model or dataset is bundled.
- `videototext.html` includes an optional local ZSL sample-collection workflow for academic research. After camera permission, a ZSL gloss, English meaning, pseudonymous signer code, and an informed-consent confirmation are required. Each recorded WebM clip and its annotations CSV are downloaded to the user's device; this static page does not upload or retain the recordings. Obtain institutional ethics approval and signer consent, secure collected clips, and follow approved retention/deletion rules. Use the collected and reviewed corpus to train and evaluate a ZSL-specific temporal model; split evaluation by signer to reduce identity leakage. ASL corpora such as [WLASL](https://github.com/dxli94/WLASL) are not ZSL and have their own computational-use terms; they can inform methods, but do not substitute for labeled ZSL data or authorize training on ZSL.
- The voice-to-sign player has an optional provider hook for genuine ZSL video. To enable it, a trusted same-origin integration script must define `window.HAND_IN_HAND_SIGN_VIDEO_PROVIDER` before `js/voice-to-sign.js` runs. The provider declares `language: "zsl"` (or `languages: ["zsl"]`) and implements `generateVideo({ text, language })`, returning a promise for `{ language: "zsl", videoUrl: "https://.../sign-video.mp4" }`. The page only accepts HTTP(S) or blob video URLs, and uses the existing dictionary-photo/fingerspelling sequence if no provider is configured or generation fails. Do not put private API keys in browser code. If the provider sends transcript text to another service, disclose that and obtain appropriate user consent. No video-generation model or signing dataset is bundled with this static project.
- Search for a word or phrase on the home page, or type into the Zimbabwean translator to show matching image files from `dictionary/` and the scanned ZSL PDF index. Alternate English meanings included in the scanned dictionary are searchable and shown alongside their matching ZSL entry.
- The Zimbabwean translator keeps sign photos in the same order as the words entered, checks alternate English meanings, and displays scanned dictionary photos in their original orientation.
- On the Zimbabwean translator, select **Record** and allow microphone access to show a live English transcript, alphabet fingerspelling, and matching ZSL dictionary photos together in the output panel. Voice input requires a supported browser, microphone permission, and a secure HTTPS connection (localhost is also supported); speech recognition may use the browser's online speech service.
- The full ZSL PDF reference is available at `dictionary/ZSL.pdf.pdf`.
- The Zimbabwean translator's alphabet preview currently uses the ASL image set; its word-photo lookup prefers ZSL dictionary images.
- Voice input on the voice-to-sign page requires a supported browser, microphone permission, and a secure HTTPS connection (localhost is also supported); speech recognition may use the browser's online speech service.
- The ordered ZSL lookup checks exact phrases, word entries, alternate English labels, and words inside multiword ZSL entries before using a fallback. Common grammatical variants and equivalents (such as "was" → "be", "not" → "no", and "I" → "me") use the matching ZSL dictionary entry while keeping the typed word as the result-card heading.
- When a word has no ZSL match, the translator displays a locally indexed ASL illustration snippet from `The Joy of Signing` in the result card and labels it as ASL, not ZSL. Words without an indexed sign illustration use clearly labelled fingerspelling. If an indexed ZSL photo fails to load, the result reports the failure and displays that fingerspelling aid.
- `js/dictionary-index.js` is the static filename index for the PNG photos in `dictionary/`. Add new PNG dictionary images to this index when updating the photo collection.
- `js/joy-sign-index.js` maps the Joy PDF vocabulary index to sign illustration snippets stored in `dictionary/joy-sign-snippets/`.
- The home page uses a hosted Unsplash photograph as a decorative background; provide internet access to load that image. Its solid-color fallback remains in place if the photo service is unavailable.

The visual palette combines deep blue, violet, and warm amber to suggest trust, inclusion, and rehabilitation. It is an independent interpretation—not an official set of brand colors or a claim of endorsement by St Daniels Rehabilitation and Vocational Training Centre or Zimbabwe Epilepsy Survivors Trust. These tools are learning aids, not substitutes for fluent signers or qualified interpreters; sign languages are distinct languages, not word-for-word versions of spoken languages.
